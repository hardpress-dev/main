Skills: How Assistants Learn Your Way of Working

Oct 20, 2026

AI assistants like Claude and ChatGPT are built on large language models (LLMs): software trained on huge amounts of text. They know a lot in general, but they don’t know your template, your style guide, or your approval steps. A skill fixes that.

What is a skill?

A skill is a folder containing a written instruction sheet and, optionally, helper files such as templates or small programs. Think of a new employee’s onboarding binder: "when a customer asks for a refund, follow these steps." The assistant reads the binder only when the task needs it.

expense-reports/
  SKILL.md        <- the instruction sheet
  policy.md       <- extra detail, read only if needed
  template.xlsx   <- the format to follow

The clever part: reading only what’s needed

An assistant can only keep so much in mind at once. So it starts with just each skill’s name and a one-line description, like a table of contents. When your request matches one, it opens that instruction sheet, and only opens the extra files if the task calls for them. You can have many skills installed without slowing it down.

Does it make the AI smarter?

Not in the sense of changing the model itself. What improves is consistency: the assistant follows a proven recipe instead of improvising. Teams often build a skill after noticing they keep re-explaining the same thing.

Skills vs. other terms you’ll hear

Background documents tell the assistant what you know. Connectors (often built on a standard called MCP) let it reach your tools and data. Skills tell it how to do the job. They work well together.

Tips for writing one

Write a clear one-line description, since that is how the assistant decides when to use it. Keep the steps short and concrete. Test it, then refine it. And since skills can include programs, only install ones from sources you trust. Skills have also been published as an open format, so more than one AI product can use them.
